# Campus Event Manager - Project Notes

## Project Summary
Campus Event Manager is a web application that helps students and
organizers discover, create, and manage events happening on campus,
such as workshops, club meetings, and fests.

## Planned Features
1. **Event Creation and Editing:** organizers can create, update, and
   cancel events with date, venue, and description.
2. **Student Registration:** students can register for events and view
   the events they have signed up for.
3. **Event Calendar View:** a calendar that shows upcoming events and
   can be filtered by category or department.
4. **Email Reminders:** automatic reminders sent before an event starts.
